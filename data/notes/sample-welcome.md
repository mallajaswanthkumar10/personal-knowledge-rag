# Welcome

This is a sample note. Replace the files in `data/notes/` with your own
markdown notes, text files, or PDFs, then run:

    python cli.py ingest
    python cli.py ask "What is this project for?"

The assistant only answers from what's actually indexed here - try asking
it something unrelated to these sample notes and it should tell you it
doesn't know, instead of making something up.
